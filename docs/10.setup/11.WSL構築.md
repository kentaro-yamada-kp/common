# WSL構築

## 概要

Windows上にLinux開発・運用ツールの基盤となるWSL 2を構築します。

## 目次

- 前提
- WSL 2有効化
- ディストリビューション
- 更新
- 動作確認

## 前提と導入

Windows Updateを適用し、BIOS/UEFIの仮想化支援機能を有効にします。管理者PowerShellで実行します。

~~~powershell
wsl --install
wsl --update
wsl --set-default-version 2
~~~

再起動後、初回起動時にLinux用ユーザー名とパスワードを設定します。必要ならwsl --list --onlineで候補を確認し、wsl --install -d Ubuntuで明示導入します。

## 確認

~~~powershell
wsl --status
wsl --list --verbose
wsl -d Ubuntu -- uname -a
~~~

VERSIONが2であることを確認します。不調時はwsl --shutdown後にDocker Desktopを再起動します。
