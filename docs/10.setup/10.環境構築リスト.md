# 環境構築リスト

## 概要

共通開発・運用基盤を構築する順序と各手順への入口を示します。

## 目次

- [Docker構築](12.Docker構築.md)

## 構築順序

1. Windowsの更新と仮想化機能を確認する。
2. WSL 2とLinuxディストリビューションを構築する。
3. Docker Desktopを導入し、WSL 2バックエンドを有効化する。
4. Docker上にJenkinsを構築する。
5. JenkinsへAWS・SSH・環境ファイルのCredentialsを登録する。
6. GitのPipeline定義を参照するPipelineジョブを登録する。

## 完了条件

PowerShellでwsl --status、docker version、docker compose versionが成功し、ブラウザからJenkinsへログインできることを確認します。
