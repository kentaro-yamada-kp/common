# Jenkins構築

## 概要

Docker Desktop上にローカルJenkinsを構築し、AWS・SSH操作に必要な認証を設定します。

## 目次

- Jenkinsコンテナ
- 初期設定
- プラグイン
- Credentials
- Pipelineジョブ
- バックアップ

## Jenkinsコンテナ

~~~powershell
docker volume create jenkins_home
docker run -d --name jenkins --restart unless-stopped -p 127.0.0.1:8080:8080 -p 127.0.0.1:50000:50000 -v jenkins_home:/var/jenkins_home jenkins/jenkins:lts-jdk21
docker logs jenkins
~~~

http://localhost:8080を開き、初期パスワードを入力します。Pipeline、Git、SSH Agent、Credentials Bindingプラグインを確認します。

## Credentials

| ID | 種別 | 用途 |
| --- | --- | --- |
| ec2-key-1 | SSH Username with private key | EC2へのSSH/SCP |
| aws-credentials | Username with password | AWSアクセスキー/シークレット |
| crane-rank-env-production | Secret file | crane-rankの本番環境ファイル |
| generic-matching-env-production | Secret file | generic-matchingの本番環境ファイル |

秘密値をジョブパラメータやPipelineへ直接記載しません。

## Pipelineとバックアップ

Pipeline script from SCMを選び、共通ジョブはcommon/jenkins配下、固有ジョブは各プロジェクトのjenkins配下を指定します。jenkins_homeにはジョブ、Credentials、プラグイン設定が含まれるため、Jenkins停止中に別媒体へバックアップし、復元テストも行います。
