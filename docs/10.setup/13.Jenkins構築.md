# Jenkins構築

## 概要

Docker Desktop上にローカルJenkinsを構築し、AWS・SSH操作に必要な認証を設定します。

## 目次

- Jenkinsコンテナ
- 初期設定
- プラグイン
- Credentials
- Pipelineジョブ
- バックアップ

## Jenkinsコンテナ

~~~powershell
docker volume create jenkins_home
docker run -d --name jenkins --restart unless-stopped -p 127.0.0.1:8080:8080 -p 127.0.0.1:50000:50000 -v jenkins_home:/var/jenkins_home jenkins/jenkins:lts-jdk21
docker logs jenkins
~~~

http://localhost:8080を開き、初期パスワードを入力します。Pipeline、Git、SSH Agent、Credentials Bindingプラグインを確認します。

## Credentials

| ID | 種別 | 用途 |
| --- | --- | --- |
| ec2-key-1 | SSH Username with private key | EC2へのSSH/SCP |
| aws-credentials | Username with password | AWSアクセスキー/シークレット |
| crane-rank-env-production | Secret file | crane-rankの本番環境ファイル |
| generic-matching-env-production | Secret file | generic-matchingの本番環境ファイル |

秘密値をジョブパラメータやPipelineへ直接記載しません。

## Pipelineジョブ作成手順

Jenkins上で各Pipelineジョブ（`nginx-deploy`, `app-deploy`, `ec2-power` 等）を新規作成し、Gitリポジトリと連携する手順は以下の通りです。

1. **新規ジョブの作成**
   - Jenkinsダッシュボードの左メニューから **「新規ジョブ作成 (New Item)」** をクリックします。
   - 任意のジョブ名（例: `nginx-deploy`）を入力し、**「Pipeline」** を選択して「OK」をクリックします。

2. **Pipeline SCM連携設定**
   - ジョブの設定画面を開き、下部の **「Pipeline」** セクションまでスクロールします。
   - **Definition** プルダウンから **「Pipeline script from SCM」** を選択します。
   - **SCM** で **「Git」** を選択します。
   - **Repositories** の **Repository URL** に、共通リポジトリのURLを入力します（例: `https://github.com/kentaro-yamada-kp/common.git`）。
     - ※プライベートリポジトリの場合は、アクセス権限を持つ Credentials を選択してください。
   - **Branches to build** の **Branch Specifier** に対象ブランチを入力します（例: `*/main`）。
   - **Script Path** にリポジトリ内のJenkinsfileの相対パスを指定します。
     - `nginx-deploy` の場合: `jenkins/nginx-deploy.Jenkinsfile`
     - `app-deploy` の場合: `jenkins/app-deploy.Jenkinsfile`
     - `ec2-power` の場合: `jenkins/ec2-power.Jenkinsfile`

3. **保存**
   - 画面下部の **「保存 (Save)」** ボタンをクリックして設定を完了します。

これにより、ジョブ実行時にGitリポジトリから最新のコードおよび設定ファイル（`jenkins/nginx.conf` 等）がワークスペースへ自動的にチェックアウトされ、パイプラインが正しく実行されるようになります。

## バックアップ

jenkins_homeにはジョブ、Credentials、プラグイン設定が含まれるため、Jenkins停止中に別媒体へバックアップし、復元テストも行います。
