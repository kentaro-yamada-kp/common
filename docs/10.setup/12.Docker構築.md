# Docker構築

## 概要

WSL 2バックエンドを使うDocker DesktopとCompose環境を構築します。

## 目次

- 前提
- Docker Desktop導入
- WSL連携
- Compose確認
- トラブルシュート

## 導入

Docker Desktop for Windowsを公式配布元から導入し、Settingsで「Use the WSL 2 based engine」を有効にします。Resources > WSL Integrationで利用するディストリビューションも有効にします。

## 確認

~~~powershell
docker version
docker compose version
docker run --rm hello-world
~~~

ClientだけでなくServer情報も表示されることを確認します。Jenkinsのデータはnamed volumeへ保存します。

## トラブルシュート

dockerが見つからない場合はターミナルを開き直し、where.exe dockerを確認します。使用量はdocker system dfで確認し、内容を確認せずdocker system prune --volumesを実行しないでください。
