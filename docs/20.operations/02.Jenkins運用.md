# Jenkins運用

## 概要

共通PipelineによるEC2電源操作、アプリ（crane-rank, generic-matching等）のデプロイ・再起動、共通Nginx設定の反映、およびJenkins自体の保守を扱います。

## 目次

- ジョブ一覧
- EC2電源管理
- 汎用アプリデプロイ
- 共通Nginx設定反映
- Credentials
- 実行履歴・保守

## ジョブ一覧

| Pipeline | 管理場所 | 用途 |
| --- | --- | --- |
| ec2-power | common/jenkins | EC2状態確認、起動、停止 |
| app-deploy | common/jenkins | 各アプリ（crane-rank, generic-matching等）のデプロイ、再起動、停止 |
| nginx-deploy | common/jenkins | 共通Nginxリバースプロキシ設定の配置・構文テスト・リロード |

## EC2電源管理

common/jenkins/ec2-power.Jenkinsfileを使用します。ACTIONはSTATUS、START、STOP、TARGET_NAMEはEC2のNameタグ、AWS_REGIONはリージョンです。PipelineはNameタグからInstance IDと現在状態を取得し、二重操作を避けてAWS CLIのwaitまで実行します。

## 汎用アプリデプロイ

common/jenkins/app-deploy.Jenkinsfileを使用します。

| パラメータ | デフォルト値 / 固定値 | 内容 |
| --- | --- | --- |
| ACTION | DEPLOY | DEPLOY（デプロイ）、RESTART（再作成）、STOP（停止） |
| PROJECT | crane-rank (ドロップダウン) | プロジェクト名（`crane-rank`, `generic-matching`） |
| BRANCH | main, develop (ドロップダウン) | デプロイ対象ブランチ |
| EC2_HOST | kykp.net | SSH接続先（EC2のPublic IPまたはホスト名） |

※ `REPOSITORY_URL` (`https://github.com/kentaro-yamada-kp/[PROJECT].git`), `ENV_CREDENTIAL_ID` (`[PROJECT]-env-production`), `APP_PORT` (`crane-rank`: 3001, `generic-matching`: 3000), `HEALTH_CHECK_PATH` (`/api/health`), および `COMPOSE_FILE` (`docker-compose.production.yml`) はPROJECTごとに自動固定化されます。

### プロジェクト別実行例

- **crane-rank**: `PROJECT=crane-rank`, `APP_PORT=3001`, `ENV_CREDENTIAL_ID=crane-rank-env-production`
- **generic-matching**: `PROJECT=generic-matching`, `APP_PORT=3000`, `ENV_CREDENTIAL_ID=generic-matching-env-production`

## 共通Nginx設定反映

common/jenkins/nginx-deploy.Jenkinsfileを使用します。

| パラメータ | デフォルト値 | 内容 |
| --- | --- | --- |
| ACTION | APPLY | APPLY（設定配置・テスト・リロード）、TEST_ONLY（テストのみ）、RELOAD_ONLY（リロードのみ） |
| EC2_HOST | - | SSH接続先 |
| CONFIG_FILE_NAME | kykp.net.conf | 配置先設定ファイル名（`/etc/nginx/conf.d/` 配下） |

共通リバースプロキシ設定（`https://kykp.net/crane-rank/`, `https://kykp.net/generic-matching/` のルーティング）をEC2のNginxへ安全に反映します。

## Credentials

| ID | 種別 | 用途 |
| --- | --- | --- |
| ec2-key-1 | SSH Username with private key | EC2へのSSH/SCP |
| aws-credentials | Username with password | AWSアクセスキー/シークレット |
| crane-rank-env-production | Secret file | crane-rankの本番環境ファイル |
| generic-matching-env-production | Secret file | generic-matchingの本番環境ファイル |

秘密値をジョブパラメータやPipelineログへ直接記載・出力しません。

## 実行前後と保守

実行前に対象ホストとブランチを確認します。完了後は秘密値がログに出ていないこと、ヘルスチェックとdocker compose psを確認します。Jenkins LTSやプラグインの更新前にはjenkins_homeをバックアップし、更新後にCredentials、SCM、SSH、代表Pipelineを確認します。
