# AWS運用

## 概要

複数プロジェクトで共有するAWSリソースの確認、起動停止、認証、費用管理を扱います。

## 目次

- AWS CLIと認証
- EC2
- ネットワーク
- IAM
- ストレージ
- コストとセキュリティ

## 共通設定

| 項目 | 値 |
| --- | --- |
| ローカルAWS CLIプロファイル | aws-dev1 |
| リージョン | ap-northeast-1 |
| EC2 Nameタグ | ec2-1 |
| EBS Nameタグ | vol-1 |
| Elastic IP Nameタグ | GIP-1 |

## 認証とEC2確認

~~~powershell
aws sso login --profile aws-dev1
aws sts get-caller-identity --profile aws-dev1 --region ap-northeast-1
aws ec2 describe-instances --profile aws-dev1 --region ap-northeast-1 --filters "Name=tag:Name,Values=ec2-1" --query "Reservations[].Instances[].{Id:InstanceId,State:State.Name,IP:PublicIpAddress}" --output table
~~~

アカウントIDと実行主体を確認します。起動停止は原則Jenkinsのec2-power Pipelineを使用します。停止中もEBS、スナップショット、Elastic IP、S3等の料金は残る場合があります。

## EC2から不要データを削除する手順

最初に削除せず、使用量と候補だけを確認します。

~~~bash
df -h
docker system df
docker ps -a
docker image ls
docker volume ls
sudo du -xhd1 /var/lib/docker /home/ec2-user 2>/dev/null
~~~

使用していない停止コンテナ、danglingイメージ、ビルドキャッシュを段階的に削除します。

~~~bash
docker container prune
docker image prune
docker builder prune
~~~

各確認プロンプトの対象を読んでから実行します。未使用イメージを広く消す場合だけdocker image prune -aを使います。

CraneRank固有データは次で一覧を確認します。

~~~bash
cd /home/ec2-user/crane-rank
ls -lh models/production models/candidates data/training data/training-work 2>/dev/null
find models/candidates -maxdepth 1 -type f -name 'image-analysis-*.pt' -print
find data/training-work -mindepth 1 -maxdepth 1 -print 2>/dev/null
~~~

本番のmodels/production/image-analysis.pt、SQLiteのDocker volume、本番環境ファイル、SSH鍵は削除しません。不要な候補モデルはファイル名を明示してrm -- ファイル名を実行し、再生成可能なtraining-workだけを対象パスを確認して削除します。

docker volume pruneとdocker system prune --volumesは永続DBを削除し得るため通常運用では禁止します。必要な場合はdocker volume inspect、DBバックアップ、復元確認を先に行います。

## セキュリティ

SSHのSecurity Groupは接続元を必要最小限にします。EC2からAWS APIを利用する場合はアクセスキーを配置せず、最小権限のインスタンスロールを使用します。
