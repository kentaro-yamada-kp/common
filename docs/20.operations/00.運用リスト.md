## 日常運用

| 目的 | 使用する手順 |
| --- | --- |
| EC2の状態確認・起動・停止 | AWS運用、ec2-power Pipeline |
| アプリの更新・再起動・停止 | Jenkins運用、app-deploy Pipeline |
| Nginx設定の反映・リロード | Jenkins運用、nginx-deploy Pipeline |
| 手動デプロイ・障害時復旧 | AWS環境デプロイ(手動) |
| Jenkins本体の更新・バックアップ | Jenkins運用 |
| アプリ固有のDB・AI操作 | 各プロジェクトの運用ドキュメント |

作業前にAWSアカウント、リージョン、EC2 Nameタグ、プロジェクト名を確認し、実行後はヘルスチェックとCompose状態を確認します。
