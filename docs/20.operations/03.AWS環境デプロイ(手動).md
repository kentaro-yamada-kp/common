# AWS環境デプロイ（手動）

## 概要

Jenkins障害時や初回環境構築時に、Webアプリ用EC2へ手動で各アプリケーション（crane-rank、generic-matching）および共通Nginxをデプロイ・反映する復旧手順を扱います。

## 目次

- 利用条件・事前準備
- アプリケーション手動デプロイ
  - crane-rank
  - generic-matching
- 共通Nginxリバースプロキシ設定・反映
- ヘルスチェック・動作確認
- ロールバック手順

## 利用条件・事前準備

通常運用時はJenkins Pipeline（`app-deploy`, `nginx-deploy`）を使用します。この手順はJenkins障害時または初回構築時に限定して実施します。
作業前にDB、現在のコミット、環境変数ファイル（`.env.production`）、本番モデル等を確認します。

### 事前確認

~~~bash
ssh -i C:\Users\admin\WorkSpace\10.projects\common\secrets\ec2-key-1.pem ec2-user@kykp.net
df -h
docker ps
~~~

## アプリケーション手動デプロイ

### 1. crane-rank のデプロイ (Port: 3001)

~~~bash
cd /home/ec2-user/crane-rank
git fetch origin
git checkout main
git pull --ff-only origin main
test -f .env.production
test -f models/production/image-analysis.pt
docker compose -f docker-compose.production.yml up -d --build --remove-orphans
~~~

### 2. generic-matching のデプロイ (Port: 3000)

~~~bash
cd /home/ec2-user/generic-matching
git fetch origin
git checkout main
git pull --ff-only origin main
test -f .env.production
docker compose up -d --build --remove-orphans
~~~

## 共通Nginxリバースプロキシ設定・反映

本環境のNginxでは、ドメイン `kykp.net` 配下で複数モジュール（`crane-rank`, `generic-matching`）をサブパスでルーティングします。

- `https://kykp.net/crane-rank/` → `http://127.0.0.1:3001/`
- `https://kykp.net/generic-matching/` → `http://127.0.0.1:3000/`

### Nginx設定の反映

`common/jenkins/nginx.conf`（または `/home/ec2-user/common/jenkins/nginx.conf`）をEC2のNginx設定ディレクトリへ配置して反映します。

~~~bash
# 設定ファイルの配置
sudo install -m 0644 /home/ec2-user/common/jenkins/nginx.conf /etc/nginx/conf.d/kykp.net.conf

# 構文チェック
sudo nginx -t

# 反映・リロード
sudo systemctl reload nginx
~~~

## ヘルスチェック・動作確認

各コンテナおよびNginx経由のエンドポイントを検証します。

### ローカル（EC2内部）からのヘルスチェック

~~~bash
# crane-rank
curl --fail http://127.0.0.1:3001/api/health
docker compose -f /home/ec2-user/crane-rank/docker-compose.production.yml ps
docker compose -f /home/ec2-user/crane-rank/docker-compose.production.yml logs --tail=100 crane-rank

# generic-matching
curl --fail http://127.0.0.1:3000/api/health
docker compose -f /home/ec2-user/generic-matching/docker-compose.yml ps
docker compose -f /home/ec2-user/generic-matching/docker-compose.yml logs --tail=100 app
~~~

### 外部（ドメイン経由）からの動作確認

ブラウザまたはcurlコマンドで以下にアクセスし、正常にレスポンスが返ることを確認します。

- `https://kykp.net/crane-rank/`
- `https://kykp.net/generic-matching/`

## ロールバック

デプロイ失敗時は原因をログで確認し、直前の既知正常コミットへfast-forward可能な修正を用意して再デプロイします。

- **crane-rank**: 本番モデルを戻す場合は保管済み世代を `image-analysis.pt` へ配置し、推論キャッシュを削除してコンテナを再起動します。
- **generic-matching**: DBマイグレーションやスキーマ変更がある場合は、必要に応じてDBバックアップからのリストアを実施します。
- **共通事項**: DBデータ（Dockerボリューム）や本番環境変数ファイル（`.env.production`）をgit操作で上書き・削除しないよう注意してください。
